# AsztalosWeboldal
Ez az oldal egy asztalos ismerősöm részére készült. A http://localhost:5173/login címen elérhető az admin felület ahonnan maga tudja feltölteni a munkáit. Ehhez a felhasználónév : Alex , jelszó : jelszo
Az oldalhoz node.js 24.11.1 -es verziót használtam
Adatbázis futtatáshoz XAMPP-ot használtam. Ehhez létre kell hozni az asztalosdb nevű adatbázist és importálni az asztalosdb.sql fájl tartalmát. Ez az előre megadott jelszó mellett tartalmaz pár példa adatot is (Ezekhez járnak a feltöltött képek).
A frontend és a backend részen is futtatni kell az npm i parancsot majd a backend-et npm start, a frontendet npm run dev (vagy npm run build és npm run preview).
